# Rock Paper Scissors

![image](https://github.com/user-attachments/assets/7ee2c894-d110-4248-b2a9-d55698222d60)

A simple yet fun and elegant paper scissor rock game for the web.

## Features

  - Easy to use interface
  - Win/lose history as you play.
  
## How to Use
  1. You can clone this repo to play in your browser or you can look at a live preview [here](https://rayalva407.github.io/rockpaperscissors/)
  2. To play simply start by clicking on your choice.
  3. The result of the round will show at the bottom and your score will be updated.
  4. If you can get to 5 points before the computer you win!
  5. To restart the game press on the Reset Game button when the game is over.
